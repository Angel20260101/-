# 六篇完整劇本

每一篇都包含：場景與人物設定、流程圖、逐節點的完整旁白與對白、每個選項的立即反應與
實際後果、心聲線索、狀態影響、所有分支與匯流、條件式對白、全部固定結局與結局判定表、
三條航線的敘事意涵與判定規則、對應的情緒練習卡與島嶼地景，以及重玩可探索的內容。

這些文件由 `npm run docs` 從 `content/stories/*.json` 產生，JSON 才是唯一的真實來源。
