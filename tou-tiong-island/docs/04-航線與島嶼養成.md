# 04｜十八條航線與島嶼養成

## 航線是什麼

每篇故事有三條主要航線，六篇共十八條。航線回答的是：
**「你這一次，是用什麼方式走過這件事的？」**

它不是評分、不是人格分類、不是情緒狀態判定。不同的選擇組合可以歸屬同一條航線。

## 判定規則

**由故事資料裡的固定規則判定，AI 完全不參與。** 同一組選擇，今天走和明年走，
在手機上走和在伺服器上走，得到的航線永遠一樣。

```jsonc
"routes": [
  { "route_id": "r_01_boundary", "priority": 1,
    "rule": { "any": [ { "var": "boundary", "op": ">=", "value": 5 },
                       { "tag": "boundary_clear", "op": ">=", "count": 2 } ] } },
  { "route_id": "r_01_dialogue", "priority": 2, "rule": { "any": [ ... ] } },
  { "route_id": "r_01_carry",    "priority": 3, "rule": { "always": true } }
]
```

規則：

1. 依 `priority` 由小到大評估，**第一個命中的航線就是結果**。
2. 最後一條（priority 3）一律是 `{"always": true}` 保底。
3. 因此任何遊玩組合都落在**恰好一條**航線上——不會沒有，也不會有兩條。

`schema/story.schema.json` 強制 `routes` 恰好三筆，`tools/validate.mjs` 另外檢查
最後一條確實是保底規則、三條航線都至少有一條路徑可達。

### 規則要和敘事意涵一致

每條航線都有 `meaning` 欄位，寫的是「什麼樣的走法算這一條」。
規則是那句話的程式版本，兩者不一致就是 bug。

開發期間確實抓到兩次這類問題：

- 故事一的協商航線 `meaning` 寫了「或找人討論」，但規則漏掉 `seek_support` 標記，
  導致「先不回 → 說今晚不行 → 找怡潔談」被保底的接住航線吃掉。修的是規則，不是期望值。
- 故事四的「爭取上台報告」本質是表達而不是建立規則，標記掛錯；同時「改掉流程」
  比「再講一次」更具代表性，應該優先判定，於是把建立規則航線提到 priority 1。

`tools/route-cases.mjs` 用 18 條人寫的設計意圖斷言把這件事鎖住。

分佈不平均是刻意的：保底航線要走到通常需要「每一步都選同一種做法」，
那是一種清楚的體驗，不該是隨便亂點就會撞上的預設值。

## 島嶼養成

| 事件 | 島上發生什麼 |
|---|---|
| 首次完成故事 | 島嶼從海面浮出、海上航線的踏腳石出現、可以命名（最多 12 字，隨時可改） |
| 發現新航線 | 長出該航線對應的地景：新地塊 ＋ 新物件 |
| 重走已發現的航線 | 不重複解鎖、不重複長地景，但累計遊玩次數 |
| 長期沒玩 | **不會退化**，什麼都不會消失 |

地景資料在 `content/island_map.json` 的 `islands[].growth[]`：

```jsonc
{
  "growth_id": "ig_01_boundary",
  "route_id": "r_01_boundary",
  "label": "界線石徑",
  "description": "一條用石頭鋪出來的小路，從屋子一直走到島的邊緣。走到底會看到海。",
  "unlock_line": "島上多了一條石徑。它沒有通往任何地方，只是清楚地標示出：這裡是邊界。",
  "hexes":     [{ "q": 1, "r": -1, "level": 1, "surface": "grass_light", "flora": "pine_grove" }],
  "landmarks": [{ "type": "stone_path", "hex": [0, 0], "offset": [0, 0.5] },
                { "type": "lamp_post",  "hex": [1, -1], "offset": [0.3, 0] }]
}
```

### 地景的意思

每條航線的地景對應它的敘事意涵，但**沒有好壞之分**：

| 航線性質 | 地景 | 為什麼 |
|---|---|---|
| 立界線 | 界線石徑 ＋ 一盞燈 | 一條不通往任何地方、只標示邊界的路 |
| 協商 | 兩岸木橋 | 本來隔著水的地方，現在走得過去 |
| 接住 | 夜間的燈 ＋ 面海的長椅 | 給那些很晚才結束的日子 |
| 撐住 | 退潮的淺灘 | 水退了，地就出現了——它一直都在 |
| 獨撐 | 避風的凹岸 | 不大，但剛好可以躲一下 |
| 燃燒 | 不滅的燈 ＋ 沙漏 | 燈會亮，但沙會流完 |

**島嶼的大小代表探索的廣度，不代表情緒健康程度。** 三條航線都走過的島，
不管是哪三條，地塊數與物件數都一樣。

## 島嶼命名

- 首次完成故事時，結算的最後一格會邀請玩家命名；可以跳過，之後在島嶼面板隨時改。
- 上限 12 字，沒有審核也沒有共享——名字只存在這個玩家自己的存檔裡。
- 預設名（界線島、回聲島、夜哨島、署名島、歸返島、歇腳島）只是起點。
