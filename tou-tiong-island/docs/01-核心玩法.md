# 01｜核心玩法與遊戲循環

## 這是什麼

《透中島》是一款結合 **3D 群島探索、日常心情紀錄、人生重來模擬器、AI 心聲回饋** 的
療癒系互動遊戲。名稱來自台語的「透中晝」——中午那段太陽最高的時間。

兩種參與強度，玩家自己決定今天要哪一種：

| | 每日任務 | 故事島 |
|---|---|---|
| 時間 | 約 5 秒 | 約 3 分鐘 |
| 頻率 | 想記就記 | 想玩再玩 |
| 內容 | 決定島上今天的天氣 | 一篇完整互動故事 |
| 強制性 | 無 | 無 |

另有每週一次、完全自願的「心情溫度計」（BSRS-5，約 60 秒）。

## 不做的事

這四條是產品的底線，所有功能設計都要過這一關：

1. **不強制每日遊玩**。沒有連續紀錄、沒有斷卡懲罰、沒有「你已經 3 天沒來」的提醒。
2. **不設標準答案**。每一個選擇都是有效的，航線名稱與文案一律中性或溫暖，不暗示優劣。
3. **不進行心理診斷**。心情溫度計是自我覺察的回顧工具，不是篩檢，不產生任何判斷。
4. **個人資料不給雇主**。故事選擇、心情紀錄、AI 回饋都不提供給雇主辨識個別員工（見 `docs/06`）。

     │                                                      │

  主島上的五個入口                        點故事島 ─────────┤
     │                                         │            │
  ┌──┴──┬──────┬──────┬──────┐                ▼            │
  ▼     ▼      ▼      ▼      ▼           走一篇故事         │
 雲朵  燈塔   碼頭   郵筒  我的紀錄        （3 分鐘）        │
 天氣  求助   許願   寫信   天氣日曆           │            │

  │      小船開到願望島                        │            │

每日天氣打卡的介面裡有一個不顯眼的連結，可以直接進每週的心情溫度計——
它不該擋在每天都要做的那件事前面。

### 透中島（主島）

入口分兩層：**島上的四個**是島的一部分，**畫面右上角的四個**是隨時都要找得到的功能。

島上的入口文字一直看得到，**直接點文字就進去**，不用先點一個圓點再點一次。
四個排成固定的一圈（角度寫死、半徑隨島的投影大小縮放），位置可預測，
手指不會點到旁邊那一個。

| 島上的地標 | 功能 | 時間 |
|---|---|---|
| 雲朵（島的正上方） | 每日任務・決定島上今天的天氣 | 約 5 秒 |
| 燈塔 | 求助資源，隨時可以點，不必說原因 | — |
| 碼頭 | 許願：希望工作環境改變什麼 | — |
| 郵筒 | 時光郵局：寫給未來的自己 | — |

| 右上角直排選單 | 功能 |
|---|---|
| 全景／回島 | 在「看整座群島」與「回到透中島」之間切換 |
| 我的紀錄 | 天氣日曆、每週顏色、航海圖、收藏、保存紀錄 |
| 登入 | 用保存代碼把另一台裝置的島接回來 |
| 關於 | 這款遊戲是什麼 |

**為什麼「我的紀錄」不放在島上**：它是隨時要找得到的東西，藏在島上就得先把鏡頭轉回主島。
放在畫面固定位置，不管你在看哪座島都按得到。島上的小屋留著當建築，只是不再是入口。

**為什麼需要「登入」**：回頭的人手上有保存代碼，但原本只能從「我的紀錄 → 保存紀錄 →
用代碼還原」三層點進去——換了手機的人根本找不到。現在放在最外層。
它名不符實（這裡沒有帳號系統），但回頭的人就是會找「登入」這兩個字，
所以按鈕照這樣寫，面板裡第一句就說清楚它是代碼不是帳號，免得有人去找「忘記密碼」。
第一次進站的三行信任說明也加了一句，告訴有代碼的人去右上角。

主島旁邊還有一座**願望島**（見下）。

#### 每日任務：決定島上今天的天氣

這是**上帝視角**：你的選擇不是在描述自己的心情，而是決定島民今天過的是什麼天氣。

- **晴／陰／雨，三選一，點一下就完成。** 沒有力氣評分、沒有自填欄位。
- 點的是島正上方那朵雲，它一直漂在最外層，不用先進任何選單。
- 選完顯示一句島上的景況（「下雨了。島民躲在屋簷下，沒有人催誰。」），
  約 1.7 秒後自動關掉。**不會再丟第二個問題給你**。
- 選的天氣會套到整座群島：天空漸層、太陽、海水、光線、雲量、雨絲，
  以及島民正在做的事（晴天熊在除草，雨天牠換雨衣整理花園；兔子從喝下午茶
  變成撐傘出門買咖啡）。
- 同一天可以重複修改，沒打卡的日子島上不會有任何損失。

為什麼砍掉力氣評分與自填欄位：這件事每天都要做，多一個問題就多一個不來的理由。
想寫字的人有時光郵局，想說工作環境的人有碼頭。

#### 每週任務：心情溫度計

**衛福部的簡式健康量表 BSRS-5 官方版本**，五題加一題附加的安全題，約 60 秒，完全自願。
入口放在每日天氣打卡裡的一個小連結，不另外佔主島的位置。

- **不對玩家顯示分數**，只顯示級距的顏色與一段說明。
- 完成就拿到紀念物，**與分數高低無關**。
- 附加題 2 分以上，不論總分多少都直接打開燈塔的求助資源（官方規則）。

題目、計分、分級與專業規範詳見 `docs/05`。

### 願望島

主島東邊的一座小沙洲，從主島的預設鏡頭就看得到。它是碼頭許願的**另一半**：

| 你做了什麼 | 島上發生什麼 |
|---|---|
| 從碼頭放出一艘小船 | 那艘船真的停到願望島的岸邊，浮在水上輕輕搖 |
| 公司回「正在處理」 | 沙地上冒出一株樹苗 |
| 公司回「做到了」 | 樹長起來 |
| 公司只是「收到了」 | **什麼都不長**，位子就空在那裡 |

點願望島會打開看板：你放了幾艘、各個主題公司回了什麼、什麼時候更新的。

兩條不能破的線：

1. **你寫的願望原文留在自己的裝置上**，不會上傳。船上只載一個主題。
2. **沒有回應就不長樹**。這裡不替公司講好話——空著的位子本身就是資訊。

公司的回應來自 `content/wish_board.json`，正式上線時由企業端後台維護，
前端只負責呈現，不會自己生成公司的回答。

### 故事島（六座）

每座島對應一篇故事，每篇故事有 **3 個決策點 × 3 個選項**、**5 個固定結局**、**3 條航線**。
走完一次的流程固定是五段，順序不變：

1. **固定劇情結局** —— 結局文案 ＋ 你每個決策點的實際後果（結局回顧）
2. **航線解析** —— 這一次走的是哪一條航線、它的敘事意涵是什麼
3. **情緒練習卡** —— 該航線對應的那張卡，自動收進長椅
4. **AI 個人化回饋** —— 選配，要按下按鈕並同意才會產生；可以直接跳過
5. **島嶼探索成果** —— 島上長出什麼、已發現幾條航線；首次完成可以替島命名

前三段永遠是預先寫好的內容，不經過 AI。

## 島嶼養成規則

| 情況 | 結果 |
|---|---|
| 首次完成某篇故事 | 解鎖該島、浮出海上航線的踏腳石、可自行命名（最多 12 字，隨時可改） |
| 走到新的航線 | 島上長出對應地景（地塊、步道、橋梁、樹林、燈⋯⋯） |
| 重走已發現的航線 | 不重複解鎖、不重複長地景、仍累計遊玩次數 |
| 長期沒玩 | **什麼都不會消失**，島嶼不會退化 |

島嶼的成長代表**探索歷程的廣度**，不代表情緒好壞——走「燃燒航線」和走「允許休息航線」
長出來的地景一樣多，只是長的東西不一樣。

## 一次完整的首玩體驗

1. 開啟 → 先看三行信任說明（公司看得到什麼、看不到什麼），只出現這一次。
2. 看到群島：中央是透中島與旁邊的願望島，周圍六片淺灘上有礁石和浮標（還沒解鎖的島）。
   主島上的五個入口文字已經在那裡了，不用先找。
3. 點島上方的雲 → 晴／陰／雨點一下 → 整座群島換成那個天氣，1.7 秒後自動關掉。
4. 點任一片未知海域 → 看到故事簡介、主題、預估時間與內容提醒 → 出航。
5. 3 分鐘的故事，三個決策點。每一段都配一張場景插圖，不是純文字往下滾。
6. 結局 → 航線解析 → 練習卡 →（可選）AI 回饋 → 島嶼浮出海面，替它取名字。
7. 回到地圖，島上多了一條石徑；還有兩條航線沒走過。

## 紀錄保存

所有紀錄預設只存在這台裝置的 localStorage：不用註冊、不留 email、
沒有任何可以對應到個人的欄位。代價是清快取或換手機就會不見，所以提供兩條帶走的路
（「我的紀錄 → 保存紀錄」）：

| 方式 | 怎麼運作 | 代價 |
|---|---|---|
| 下載備份檔 | 匯出一個 JSON 檔，換裝置時讀回來 | 檔案要自己保管 |
| 保存代碼 | 拿一組 `TTI-XXXX-XXXX`，自己設密碼，換裝置輸入兩樣就接回來 | **密碼忘記就真的解不開** |

保存代碼是**端對端加密**：整份存檔在瀏覽器裡加密完才上傳，伺服器只收得到密文，
沒有密碼解不開，也無從得知那是誰的島。技術細節見 `docs/06`。

介面上必須把「忘記密碼沒救」這件事講在前面，不能等出事才說。

## 重玩設計

採「重要選擇真正改變劇情、短分支後適度匯流」：

- 每個決策點後有專屬的分支節點（立即反應、後續事件都不同），再在匯流節點收束。
- 匯流節點用**條件式對白**保留前面選擇的痕跡，所以同一個場景讀起來不一樣。
- 中段有**條件分流**：例如故事一的「星期四早上」有三個版本，由你前一晚睡了多久決定。
- 配角的台詞會隨路徑改變（怡潔、小薇、美姐、阿凱、小魚都是這樣寫的）。

每篇故事有 27 條可走完的路徑。全部 6 篇共 162 條，每一條都保證能走到結局
（由 `tools/validate.mjs` 窮舉驗證）。
